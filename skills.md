# AWS SBG @ SSPU — Hybrid Design System (re:Invent × Builder Center)

## 1. Visual Identity & Hybrid Color Tokens
- **Canvas Base:** `#080b11` (Obsidian re:Invent stage black)
- **Container Surfaces:** `#0f1523` (Deep midnight navy)
- **Elevated Cards:** `#151d30` with border `1px solid #232f48`
- **re:Invent Neon Magenta / Violet:** `#d946ef` / `#a855f7` (Keynotes & primary spotlights)
- **AWS Smile Orange:** `#ff9900` (Core CTAs & registration highlights)
- **re:Invent Electric Cyan:** `#00f0ff` (Telemetry & technical indicators)
- **Gradient Accents:** `linear-gradient(135deg, #a855f7 0%, #ff9900 100%)` (re:Invent Hero banners)
- **Primary CTA Buttons:** Solid white `#ffffff` with dark text `#080b11` (rounded-md, font-bold) OR AWS Orange `#ff9900` with subtle neon glow.

## 2. Typography & Layout Architecture
- **Display Headlines:** Ultra-bold sans-serif (`Inter`, `font-extrabold` / `font-black`) with re:Invent gradient text highlights.
- **Code & Metadata:** `JetBrains Mono` / `Fira Code` for session IDs, Builder IDs, timestamps, and terminal widgets.
- **Three-Column Shell:**
  1. *Left Rail:* Builder Center retro navigation tree with active violet/purple pill tabs.
  2. *Center Stage:* re:Invent style immersive hero, spotlight marquee, curated track tabs, and interactive canvas tools.
  3. *Right Rail:* Spaces directory + Live Campus Telemetry (Lab 3 status, next jam, verified attendance).

## 3. Strict Real-Data Integrity
- No arbitrary numbers. All stats are computed from the real registered student builders, actual sessions conducted in SSPU Lab 3, and verifiable PRN-based certificates.
